# Megha React Portfolio

React + Vite conversion of the supplied portfolio HTML.

## Component structure

- `src/components/Header/` → Header + Navbar
- `src/components/Hero/` → Hero section
- `src/components/About/` → About section
- `src/components/Skills/` → Skills section
- `src/components/Projects/` → Projects section
- `src/components/Contact/` → Contact section
- `src/components/Footer/` → Footer
- `src/styles/global.css` → Global/reset styles
- `src/App.jsx` → Main component composition

Each component has its own `.jsx` and `.css` file.

## Run

```bash
npm install
npm run dev
```

Then open the Vite local URL shown in the terminal.

## Resume

Place `Megha_More.pdf` inside `public/` for the Resume buttons to work.
